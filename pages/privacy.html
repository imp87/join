Privacy Policy

1. Introduction

Welcome to Join. Protecting your personal data is important to us. This Privacy Policy explains which data is collected, how it is used, and how it is protected when using this application.

2. Data We Collect

When using Join, the following data may be collected and stored:

  • User name
  • Email address
  • Password authentication data
  • Contacts created within the application
  • Tasks, subtasks and project-related information

3. Use of Firebase

Join uses Firebase services provided by Google to enable core application functionality. Firebase Authentication is used for user login and registration. Firebase Realtime Database may be used to store user-related data such as contacts, tasks and project information.

4. How We Use Your Data

The collected data is used only to provide the functionality of Join. This includes creating and managing user accounts, logging users in, displaying contacts, and creating, editing or organizing tasks.

5. Data Sharing

We do not sell, trade or share personal data for marketing purposes. Data may be processed by Firebase as a technical service provider in order to operate the application.

6. Data Security

We use reasonable technical measures to protect stored data from unauthorized access, loss or misuse. Passwords are handled through Firebase Authentication and are not stored in plain text by Join.

7. Data Retention

Personal data is stored only as long as it is needed for the use of the application. Users may request deletion of their account and related data.

8. User Rights

Users may request access to their personal data, correction of incorrect data, or deletion of their stored data.

9. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time. Any changes will be published on this page.

10. Contact

If you have questions about this Privacy Policy, please contact the application administrator.
